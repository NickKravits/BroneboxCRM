Интеграция с RealtyCalendar
Webhook
Инструкция
1
Войдите в личный кабинет RealtyCalendar и перейдите в раздел Настройки → Webhook
2
Нажмите Добавить Webhook и вставьте скопированный URL в поле адреса
3
Выберите события: Новое бронирование, Отмена бронирования, Изменение бронирования
4
Сохраните настройки. BroneBox начнёт получать данные автоматически
Интеграция с OkiDoki
API key
Инструкция
1
Войдите в личный кабинет OkiDoki и перейдите в раздел Настройки → API
2
Скопируйте API key и вставьте скопированный ключ в поле
3
Перед сохранением - Создайте шаблон договора с полями "Название и описание объекта", "Дата заезда", "Дата выезда", "Обеспечительный платёж", "Цена за одни сутки", "Предоплата". Не забудьте добавить шаблоны для поля "Название и описание объекта"
4
Сохраните настройки. Вы получите список вашегих шаблонов и ID строк
5
Вставьте ID строк в настройках объекта или объектов. Договоры начнут формироваться автоматически
